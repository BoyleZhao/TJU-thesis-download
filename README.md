# 天津大学论文平台下载工具

适用于天津大学学位论文阅读页面(https://theses.lib.tju.edu.cn)的用户脚本。打开有权访问的论文后，脚本可尝试逐页加载页面图像，并在浏览器中将其整理导出为 PDF。

> **快速安装：**[前往 Greasy Fork 安装脚本](https://greasyfork.org/zh-CN/scripts/598023-tju-thesis-download-%E5%A4%A9%E6%B4%A5%E5%A4%A7%E5%AD%A6%E8%AE%BA%E6%96%87%E5%B9%B3%E5%8F%B0%E4%B8%8B%E8%BD%BD%E5%B7%A5%E5%85%B7)

## 功能

- 在论文阅读页面提供“⬇ 下载PDF”按钮
- 逐页滚动，尝试触发页面图像加载
- 显示加载、转换和 PDF 生成进度
- 根据页面图像的方向生成 PDF

## 安装方法

### 通过 Greasy Fork 安装（推荐）

1. 在浏览器中安装用户脚本管理扩展，例如 **Tampermonkey（油猴）**。可以在 Chrome、Edge 或 Firefox 的扩展商店中搜索并安装。
2. 打开本脚本的 [Greasy Fork 页面](https://greasyfork.org/zh-CN/scripts/598023-tju-thesis-download-%E5%A4%A9%E6%B4%A5%E5%A4%A7%E5%AD%A6%E8%AE%BA%E6%96%87%E5%B9%B3%E5%8F%B0%E4%B8%8B%E8%BD%BD%E5%B7%A5%E5%85%B7)。
3. 点击页面上的**“安装此脚本”**，在用户脚本管理器弹出的确认页面中完成安装。

已经打开论文阅读页面的用户，安装后请刷新页面。后续更新可通过 Greasy Fork 页面或用户脚本管理器查看，具体取决于扩展的更新设置。

### 从仓库手动安装

在仓库中打开 `.js` 脚本文件，点击 **Raw**，再按照用户脚本管理器的提示安装。如果没有自动弹出安装页面，也可以在管理器中创建新脚本，将文件内容粘贴进去并保存。

## 使用方法

1. 使用已安装脚本的浏览器，打开有权访问的天津大学学位论文**阅读页面**。
2. 等待页面加载完成，找到右上角的 **“⬇ 下载PDF”** 按钮。
3. 点击按钮，等待脚本加载页面图像并生成 PDF。处理期间请尽量不要关闭或刷新页面。
4. 按浏览器提示保存文件。

论文页数较多时，生成过程可能需要较长时间，也可能占用较多浏览器内存。导出结果取决于阅读页面结构和图像加载情况，**不保证每篇论文都能完整导出**。保存后建议核对 PDF 页数及顺序。

## 常见问题

**没有出现下载按钮？**  
请确认用户脚本管理器和本脚本均已启用，当前打开的是论文阅读页面，而不是检索或详情页面；随后刷新页面重试。

**一直提示加载，或导出的页数不足？**  
请先确认论文页面能够正常显示图像，再尝试重新加载页面。网络状况、浏览器性能及平台页面结构变化都可能影响结果。

**点击后没有保存 PDF？**  
请检查浏览器是否拦截了下载，并确认网络可以加载脚本依赖的 PDF 库。
