> # TJU-thesis-download 天津大学论文平台 PDF 导出脚本
>
> 一个适用于天津大学学位论文阅读页面的油猴脚本。在用户正常访问论文阅读页面时，脚本会尝试逐页触发图像加载，收集已加载的页面图像，并在浏览器本地整理导出为 PDF。
>
> **主要功能**
> - 在论文阅读页面显示“下载 PDF”按钮
> - 逐页滚动，触发页面图像加载
> - 显示加载与 PDF 生成进度
> - 根据页面图像方向生成 PDF
>
> **使用说明**：安装支持用户脚本的浏览器扩展，导入本仓库的 `.user.js` 文件，然后打开相应论文的阅读页面使用。导出效果取决于页面结构、图像加载情况及浏览器性能。
>
> **使用声明**：本脚本仅供有权访问相关文献的用户学习与个人研究使用。请遵守平台使用规则及著作权要求，勿未经授权传播导出的文件。
